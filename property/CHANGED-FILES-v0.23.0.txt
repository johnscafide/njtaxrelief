Important deployment note
-------------------------
The direct customer UI is now role-gated, and paid access is disabled for
non-developers. Because this site is statically hosted, HTML/JSON placed in a
public web directory is still a public static asset at the HTTP layer. Data
that must be confidential (rather than merely inaccessible through the app)
must be moved behind a server/Edge Function or an RLS-protected Supabase
resource before it can be treated as secret.
