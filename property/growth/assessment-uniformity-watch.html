Assessment Uniformity Watch

Compare New Jersey municipal assessment-roll consistency using the Division of Taxation's property assessment uniformity measures. Start with the municipalities showing wider residential dispersion, then review the underlying property facts before deciding whether any parcel deserves appeal analysis.

Municipal context, not a case outcome
This workflow does not decide whether a parcel is over-assessed or whether an appeal should be filed. It organizes already-governed municipal uniformity evidence so a professional can decide where deeper factual review may be worthwhile. No filing deadline, fee, owner contact data, protected-trait inference or legal outcome is generated here.

How to use this Play
  • Start with residential COD or the existing Watchdog uniformity score to prioritize municipal research.
  • Use sales count and source year to understand how much evidence supports the displayed residential measure.
  • Commercial and vacant COD are displayed separately when the State source provides them. They are not substituted for residential evidence.
  • A COD above 15 is highlighted only as context against the residential standard already documented in the governed source file. It is not an appeal threshold.

The Watchdog uniformity score is an existing derived score from the governed data file. This page does not recompute the score, create a new appeal probability, or impute missing values.

PROVENANCE

Evidence boundary

State source

NJ Division of Taxation, Measures of Property Assessment Uniformity. The governed file stores the residential segmented coefficient, source series, sales count and available general, commercial and vacant coefficients by district.

Watchdog derivation

The existing uniformity score is weighted toward recent residential evidence and accounts for volatility and thin samples. The source file documents the scoring method and keeps the raw State measures beside the score.

Missing values remain missing. No neighboring-town substitution, owner identity, contact enrichment, demographic inference, filing deadline, fee setting, outcome prediction or ROBUST/Watchdog Score mutation occurs in this workflow.
