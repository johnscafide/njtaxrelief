4

Daily Intelligence / Today inbox

COMPLETE · PRODUCTION

Daily Intelligence is now an actual triage inbox rather than a read-only digest. The latest governed queues become owner-specific review work that can be completed, deferred, dismissed, reopened, and learned from without rewriting the underlying Intelligence evidence.

  • A new RLS-protected, append-only intelligence_today_events trail persists reviewed, snoozed, dismissed, and reopened actions. Authenticated users have only owner-scoped SELECT + INSERT; update/delete/truncate-style privileges are not granted.
  • Each queue item is keyed to the governed digest/model/property combination. Handling an older digest does not permanently hide a property: a new governed digest creates a new review item when evidence changes.
  • Today now shows open, snoozed, handled, and latest-queue counts; a 24-hour snooze returns automatically; handled items can be inspected and reopened.
  • Review property records the triage event before taking the user to Property Home, preserving a reconstructable decision trail.
  • Meaningful triage actions also feed the Context Graph as observed user behavior with a digest evidence reference. They are not promoted into property truth or inferred intent merely because the user clicked a button.
  • The prior Today-layer schema bug was fixed: it queried a nonexistent generic confidence field; the live Intent State correctly uses active_job_confidence. Confirmed research context can now actually shape the inbox copy.
  • The safety contract explicitly states that model score is not action certainty and that the queue is not a prediction of seller intent, value, profit, urgency, or outcome.
  • Production verification confirmed RLS owner policies, authenticated SELECT/INSERT-only privileges, and a direct covering index for the digest foreign key. The performance advisor no longer reports the Today digest FK as unindexed; immediate unused-index notices are expected before user traffic.
  • The Access Boundary workflow now includes property/tests/intelligence-today-contract.mjs, covering syntax, Intent State field correctness, append-only privileges, RLS, Context Graph logging, digest renewal semantics, safety copy, responsive UI hooks, and the no-?v= rule.
  • All related Vercel production deployments reached READY.
