# Watchdog Mobile Audit — Run 061

**Timestamp:** 2026-08-22 08:34 ET  
**Page:** `/property/data-center/`  
**Area audited:** Build Sheet + Export CSV workflow; generated result sheet; async feedback; stale-result failure state; result overflow/keyboard inspection; typography

## Finding
The generated-sheet workflow still had a substantive mobile certification risk. `Build sheet` changed only the result-note paragraph to “Resolving…” while the primary action itself exposed no busy state. If a rebuild failed after a previous successful build, the prior generated table could remain visible while the note reported the new failure, creating a risk that stale results could be mistaken for the current request. The generated result table was horizontally scrollable, but it had no mobile inspection region semantics, no sticky row-context column, and only 12px table text.

## Typography/readability assessment
The result sheet is an evidence/data surface and should not be converted into a lossy summary. Mobile generated-cell text is now 13px with 1.45 line-height and 12px sticky headers; the result note is 14px with 1.5 line-height. Build/Export controls retain the previously certified 48px mobile touch sizing. Status feedback is 14px and safe-area aware.

## Preserve vs. redesign decision
Preserve the arbitrary-column tabular result because users explicitly choose the fields and CSV-oriented evidence is inherently tabular. Do not collapse selected fields into cards or hide columns. Instead, keep horizontal scrolling contained inside the result module, add sticky top headers and a sticky first selected column for context, allow long values to wrap within bounded columns, bound the sheet by dynamic viewport height, and make the sheet a keyboard-focusable labeled region.

- Added `property/css/data-center-mobile-results.css`, loaded only at `<=720px`.

- Export CSV now exposes brief `aria-busy` / `Exporting…` feedback and announces completion without altering the existing CSV generation path.
- Added safe-area-aware 14px transient result status feedback.
