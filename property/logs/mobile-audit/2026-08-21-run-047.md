# Watchdog Mobile Audit — Run 047

**Timestamp:** 2026-08-21 19:37 ET  
**Page:** `/property/marketing-studio/design/`  
**Area audited:** dynamic template selection, async/busy feedback, stalled-load recovery, proof/template preview containment, narrow-phone viewport behavior

## Finding

The Design route had already received a mobile typography/touch pass in Run 046, but its critical selection path still had two certification risks. Template `Use` actions can wait on provider detail/RPC work without a deterministic mobile busy state, leaving a user unsure whether the tap registered. Separately, if the initial wizard bootstrap stalls, the route can remain on `Opening Marketing Studio…` indefinitely with no recovery action. Large provider/template/proof imagery also lacked a route-specific dynamic-viewport ceiling and could dominate the usable phone viewport.

## Typography/readability assessment

Run 046 established the primary Design mobile baseline: operational UI is generally 12–17px, primary fields are 16px/48px, and critical actions are 44–48px+. Run 047 keeps that baseline and adds a recovery state with a 19px heading, 15px explanatory copy, and a 48px/15px retry action. No new 8–10px operational copy was introduced.

## Preserve vs redesign decision

The creative/template imagery is decision-critical and should not be omitted or reflowed into a lossy summary. Preserve the artwork geometry, but contain the viewing surface on phones. Mobile now bounds preview containers to 58dvh (52dvh at <=420px) and images to 52dvh (46dvh at <=420px), with contained scrolling where needed. Selection workflow logic remains unchanged; only mobile feedback/recovery is added.
