# Watchdog Mobile Audit — Run 058

**Timestamp:** 2026-08-22 05:37 ET  
**Page:** `/property/agent-desk/` — Agent Control  
**Area audited:** Private-sphere importer focus/keyboard lifecycle; final Agent Control certification review; Data Center handoff

## Finding
The private-sphere importer was already visually rebuilt as a phone-native bottom sheet and the authoritative importer runtime already locked body scroll while open, but the modal still lacked the final mobile keyboard/focus lifecycle required for certification. Opening it left focus wherever the user had been, Escape did not dismiss it, Tab could leave the dialog, and closing did not restore focus to the invoking “Add your sphere” / “Import or select properties” control. This is a real accessibility and usability failure for keyboard, switch-control and assistive-technology users.

## Typography/readability assessment
The importer’s existing mobile certification CSS already uses the established Watchdog mobile baseline: 23px modal title, 15px primary explanatory copy, 13–14px supporting/status text, 16px CSV input text, 14–15px controls and 44–48px touch targets. No additional font-size reduction or desktop-density compromise was required in this run.

## Preserve vs. redesign decision
Preserve the existing saved-property/CSV importer and its Supabase-backed import path because it is core Agent Control functionality. Preserve the mobile bottom-sheet presentation introduced earlier. Add only the missing mobile focus lifecycle rather than modifying desktop modal behavior or creating a second importer implementation.

## Change
- Added `property/js/agent-import-mobile-a11y.js` with a hard `max-width:760px` activation guard.
- Tracks which of the two importer triggers opened the modal.
- Moves initial focus to the 44x44 close control when the importer opens.
- Adds Escape-to-dismiss.
- Traps Tab / Shift+Tab inside the active dialog.
- Restores focus to the original opener when the importer closes, with the primary header importer action as fallback.
- Updated `property/js/agent-control-shell-2027.js` to load the mobile importer accessibility runtime alongside the existing Agent Control mobile/evidence assets.
- Existing `agent-desk.js` open/close/import behavior, body-scroll lock, validation, chunked upsert, and data reload flow were not altered.
