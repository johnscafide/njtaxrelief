# Watchdog Mobile Responsiveness Audit — Run 029

**Timestamp:** 2026-08-21 01:33 ET  
**Page:** `/property/marketing-studio/customize/`  
**Area audited:** shared campaign-review modal / modal-sheet behavior, viewport containment, touch dismissal, typography, body scroll, keyboard focus

## Finding

Marketing Studio Customize inherits the shared `.ms-modal` campaign-review surface from `property/css/marketing-studio.css`. The desktop implementation centers a card with `max-height:90vh` and an icon-only close button whose visual size is set only by `font-size:22px`. The open/close behavior in `property/js/marketing-studio.js` only toggles `hidden`; it does not lock background scrolling, add dialog semantics, trap keyboard focus, support Escape dismissal, or restore focus to the invoking control.

On mobile this creates a certification risk on short iPhone/Android viewports and devices with safe areas: the modal can leave awkward inaccessible space, the dismiss target is not guaranteed to meet the 44px touch minimum, background content can remain scrollable behind the overlay, and keyboard users can tab outside the dialog.

## Typography/readability assessment

The base modal inherits desktop-density supporting copy and step metadata. For the mobile presentation, primary modal copy is now 15px with 1.5 line-height, warning copy 14px, step titles 14px, step metadata 12px, and the eyebrow 12px. These values are within the current Watchdog mobile SaaS typography standard and remain readable without pinch-zoom.

## Preserve vs. redesign decision

**Redesign for mobile, preserve desktop.** The campaign-review content is important and should not be omitted. A centered desktop dialog is not the best phone presentation, so mobile now renders it as a bottom sheet with dynamic-viewport and safe-area containment. Desktop keeps the original centered modal unchanged.

## Change

Added `property/css/marketing-studio-mobile-modal-audit.css`, loaded only at `max-width:700px`, which:

- converts `.ms-modal` to an edge-to-edge mobile bottom sheet;
- uses `100dvh`-based max-height plus `env(safe-area-inset-top/bottom)`;
- keeps the modal header sticky so dismissal remains reachable during long review content;
- gives close/dismiss controls a deterministic 44×44px minimum target;
- raises modal/sequence/warning typography to mobile-readable sizes;
- contains vertical scrolling inside the sheet with overscroll containment;
- prevents background body scrolling while the mobile modal is open;
- stacks the sequence timing metadata under the step content below 420px instead of squeezing a three-column row.

Added `property/js/marketing-studio-mobile-modal-audit.js`, scoped by `matchMedia('(max-width: 700px)')`, which:

- adds `role="dialog"`, `aria-modal="true"`, and heading association;
- adds an accessible label to the icon-only close control;
- focuses the dismiss action when the modal opens;
- traps Tab / Shift+Tab focus inside the open dialog;
- supports Escape dismissal;
- restores focus to the invoking control when the modal closes;
- synchronizes body-scroll locking when the shared runtime toggles the modal `hidden` attribute.

`property/marketing-studio/customize/index.html` now loads the new CSS with `media="(max-width: 700px)"` and loads the accessibility guard after the existing Marketing Studio runtime scripts.
