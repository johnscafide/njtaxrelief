## Area audited
Final Property Home certification pass, focusing on the newer embedded Property Dashboard (`.wdpd`) module at phone widths: mobile typography/readability, filter/form sizing, marker-list interaction density, touch targets, and whether the desktop information architecture should be preserved or re-presented on phones.

## Finding
A substantive certification failure remained in `property/css/home/07-property-dashboard.css`. Its <=680px and <=430px rules intentionally reduced several operational elements below acceptable mobile-SaaS readability levels, including 8px metric/legacy labels, 9px metric supporting text, 11px section explanatory text, 11px filter controls, 11px fact values, 11px marker titles, and other 8–10px marker/tier/provider/status labels. Several marker actions and explorer controls also lacked a deterministic 44px mobile touch target. The layout responded, but the information was too dense to qualify as mobile-ready.

## Typography/readability assessment
**FAIL before fix / PASS for the audited Property Dashboard surfaces after fix.**
- Operational labels/tier/provider/legacy labels promoted to 12px.
- Section/marker explanatory copy promoted to 14px with 1.5 line-height.
- Supporting metric/fact/status text promoted to 12px.
- Marker titles promoted to 14px.
- Filter inputs/selects promoted to 16px and 44px high to improve readability and avoid mobile browser input zoom behavior.
- Critical marker/explorer actions now have 44px minimum touch height and 13px labels.

## Preserve-vs-redesign decision
**Preserve the Property Dashboard information architecture, redesign its mobile density.** The module's metric, facts, filter, and marker-list structure is useful on phones and already collapses to one/two-column responsive layouts. Replacing it wholesale would remove useful scanability. The correct mobile treatment is to promote text, enlarge controls/icons, remove artificial marker-description line clamping, and keep narrow-phone marker result alignment deliberate.

## Change
Updated `property/css/home/home-menu-sync.css` with mobile-only `@media(max-width:820px)` overrides for the `.wdpd` module. The overrides use `!important` because `07-property-dashboard.css` is loaded later and contains the undersized <=680px/<=430px values being corrected. Changes include:
- 12–14px operational/support typography across metrics, facts, panels, filters, marker rows, status/tier/provider tags, summaries, and legacy dividers.
- 16px / 44px filter controls.
- 44px minimum touch targets for explorer actions, locked-marker upgrade actions, load-marker, and show-more controls.
- 44px marker icons and adjusted row geometry.
- Removal of mobile marker-description line clamping so important explanation remains readable without expansion or pinch zoom.
- <=430px result alignment reset so narrow phones do not retain unnecessary left indentation.
