## Area audited
Remaining dashboard mobile interaction surfaces, with emphasis on portfolio horizontal behavior and overlay dismissal controls.

## Finding
The dashboard portfolio layer already has horizontal overflow handling in the legacy/pro table wrapper, so no new table rewrite was justified in this pass. A definite mobile interaction failure was found in the active Agent Intel overlay instead: `property/css/dashboard/06-responsive-additions.css` defines `.mobile-intel-close` at only 34x34px inside the `@media (max-width: 760px)` mobile sheet. This close control dismisses a modal-style mobile overlay and falls below Watchdog's 44px minimum touch-target standard.

## Change
Updated the existing mobile-only certification stylesheet `property/css/dashboard/dashboard-mobile-audit.css`:
- Increased `.mobile-intel-close` to 44x44px minimum at mobile/tablet widths.
- Added `touch-action: manipulation` for reliable tap handling.
- Adjusted the inset slightly so the enlarged control remains comfortably inside the sheet edge.
- Left all desktop Agent Intel sizing and behavior unchanged.

## Desktop isolation
**PASS.** The fix lives only inside `dashboard-mobile-audit.css`, which is loaded by the dashboard with `media="(max-width: 768px)"`, and the new rule itself is inside that stylesheet's `@media (max-width: 768px)` block. No base desktop CSS was changed.
