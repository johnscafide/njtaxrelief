## Finding
A substantive mobile certification risk remained in the shared explainer modal implementation. The base dialog was still centered using a desktop presentation with `max-height: min(86vh, 900px)`, a 34×34 close button, and no mobile-safe-area treatment. More importantly, shared CSS already defined `body.note-modal-open { overflow: hidden; }`, but the `/property/home` `plModalNote()` / `plCloseNote()` implementation never applied or removed that class. On phones, the background page could therefore remain scrollable behind a long dialog. The modal also did not add dialog semantics, mobile focus containment/restoration, or Escape dismissal. Auth content rendered inside the same surface, so undersized controls/keyboard zoom were certification risks as well.

## Typography/readability assessment
**FAIL before fix / PASS for the audited modal surfaces after fix.**
- Dialog heading: 19–20px.
- Primary modal body/list/glossary copy: 15px with 1.55 line-height.
- Form labels/supporting copy: 13px.
- Inputs/selects/textareas: 16px and 48px minimum height to remain readable and avoid mobile browser input zoom.
- Modal buttons/actions: 44px minimum, with primary auth actions at 48px / 15px.
- No important modal content requires pinch zoom.

## Preserve-vs-redesign decision
**Preserve content and workflows; redesign the mobile container.** The note/glossary/comparison/auth information is important and should not be hidden on phones. The centered desktop dialog was replaced on mobile with a bottom-sheet presentation using dynamic viewport sizing and safe-area padding. Wide comparison/table content remains available through contained horizontal scrolling inside the sheet rather than causing page-level overflow.

## Change
Added two dedicated mobile-only audit layers and loaded them from `/property/home/index.html`:

- `property/css/home/home-mobile-modal-audit.css`
  - Loaded with `media="(max-width: 820px)"`.
  - Converts the note surface to a bottom sheet.
  - Uses `100dvh` and `env(safe-area-inset-*)` for dynamic viewport/notch/home-indicator containment.
  - Promotes the close control to 44×44.
  - Promotes modal typography and form controls to the mobile certification baseline.
  - Makes auth controls stack vertically and keeps wide comparison content locally scrollable.
  - Adds explicit `:focus-visible` treatment.

- `property/js/dashboard/home/home-mobile-modal-audit.js`
  - Activates only when `matchMedia('(max-width: 820px)')` matches at load.
  - Wraps the existing `plModalNote()` / `plCloseNote()` behavior without changing the underlying desktop implementation.
  - Applies/removes `note-modal-open` so background scrolling is locked on mobile while the dialog is open.
  - Adds `role="dialog"`, `aria-modal="true"`, heading association, and `aria-hidden` state.
  - Focuses the close control on open, traps Tab focus within the active sheet, supports Escape dismissal, and restores focus to the invoking control on close.
