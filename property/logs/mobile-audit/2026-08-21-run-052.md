# Watchdog Mobile Audit — Run 052

**Timestamp:** 2026-08-21 23:37 ET  
**Page:** `/property/marketing-studio/admin/` — Direct Mail Analytics  
**Area audited:** Customer-search performance / post-certification hardening

## Finding
The current authoritative analytics runtime can load up to 500 customer records (`p_limit:500`), and the customer-search handler rebuilt the entire matching mobile card set synchronously on every input event. After the prior mobile table-to-card redesign, a single keystroke could therefore trigger hundreds of multi-field card DOM replacements. This is a substantive mobile responsiveness/performance risk on slower phones and can make text entry feel sticky even though the search remains functionally correct.

## Typography/readability assessment
The current mobile audit layer already keeps primary explanatory copy around 15px, supporting/operational copy around 12–14px, search/select inputs at 16px, and primary/recovery/navigation controls at 44–48px minimum. This post-certification pass did not find remaining 8–10px decision-critical text in the mobile presentation. Long ledger values wrap and the prior desktop 9-column tables remain presented as stacked cards on mobile.

## Preserve vs. redesign decision
Preserve the existing authoritative customer-search/filter logic, analytics data path, and mobile card presentation. Do not create a second mobile search implementation or reduce available customer evidence. Instead, reduce redundant render work by deferring the existing render operation with a short mobile-only debounce.

## Change
- Added `property/js/marketing-studio-admin-mobile-performance.js`.
- At `<=720px`, customer-search input events are intercepted and debounced by 160ms before being re-dispatched to the existing `marketing-studio-admin.js` search handler.
- The shim does not alter filtering semantics, customer data, RPC calls, row/card markup, or search results; it only reduces redundant intermediate DOM rebuilds while the user is typing.
- Above 720px the performance shim exits before attaching any listener, preserving desktop behavior.
- Wired the new script after the authoritative admin runtime in `property/marketing-studio/admin/index.html`.
