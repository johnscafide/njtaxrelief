# Watchdog Mobile Audit — Run 024

**Timestamp:** 2026-08-20 20:32 ET  
**Page:** `/property/marketing-studio/customize/`  
**Area audited:** Marketing Studio creative workspace shell, editor toolbar, canvas presentation, inspector/form controls, composer controls, template strip, recipient controls, typography and touch sizing.

## Finding

The Marketing Studio customize route had responsive breakpoints, but the phone presentation still behaved like a compressed desktop editor. The production workspace shipped multiple operational controls at 9–12px, including 10px tool-rail labels, 11px stage metadata, 11px inspector labels, 12px inspector inputs, 9–11px template labels, 9–10px recipient controls, and 8–10px Watchdog Designs composer controls. Several interactive controls also lacked a deterministic 44px touch height.

The creative canvas itself was also being reduced to roughly 94–96% of the phone width. That makes the authored postcard artwork visually fit, but forces print-scale text and details to become too small to inspect comfortably. For a design workspace, simply shrinking the desktop canvas is not an acceptable mobile presentation.

## Typography/readability assessment

**Failed before change.** Operational editor copy in the 8–12px range is below the Watchdog mobile certification baseline for a professional SaaS workflow. Form controls at 12px also create poor readability and an iOS focus-zoom risk. The authored postcard typography is treated separately from editor chrome because changing those print dimensions would alter the actual creative output.

## Preserve vs. redesign decision

- **Preserve:** the actual postcard/front-back artwork geometry and desktop print composition. These are the design artifact and must not be rewritten solely for phone viewport width.
- **Redesign for mobile:** the surrounding editor chrome and canvas viewport. The desktop vertical tool rail becomes a readable horizontal command strip; the inspector becomes a mobile form surface; and the postcard becomes a controlled pan/zoom viewport instead of being continuously shrunk until its designed copy is unreadable.

## Change

Added `property/css/marketing-studio-mobile-audit.css` and load it only from the Customize route at `media="(max-width: 700px)"`.

Mobile changes include:

- topbar/view controls raised to 13–14px with 44px+ touch targets;
- tool strip labels raised to 13px with 52px-high, 92px-wide snap targets;
- stage metadata raised to 13px;
- creative canvas uses a 560px mobile working surface (520px at <=420px) inside a contained touch-pan/scroll viewport, preserving true artwork geometry rather than shrinking it to phone width;
- inspector labels raised to 13px, headings to 18px, supporting copy to 13px;
- inspector/search inputs and selects raised to 16px with 48px minimum height; textarea minimum 104px;
- inspector actions raised to 14px / 48px;
- template names raised to 14px and supporting labels to 11px;
- Watchdog Designs composer controls raised from 8–10px to 12–16px and critical actions to 44–48px;
- recipient filters/actions raised to 12–16px with 44px+ controls;
- mobile inspector receives bottom safe-area padding.
