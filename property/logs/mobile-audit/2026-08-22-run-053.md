# Watchdog Mobile Audit — Run 053

**Timestamp:** 2026-08-22 00:37 ET  
**Page:** `/property/agent-desk/` — Agent Control  
**Area audited:** Mobile work-navigation + Add your sphere/import modal accessibility, touch sizing, typography, safe-area and viewport behavior

## Finding
Agent Control had an active mobile certification failure in its top workspace controls and private-sphere importer. The base 2027 CSS intentionally reduced the mobile workspace tabs to 10px below 560px and hid `.ac27-label`, which is the visible text inside the `Add your sphere` button. Because that button has no separate `aria-label`, hiding the text also removes its accessible name from the mobile presentation. The same 2027 layer forced `.ad-modal-x` back to 36×36px with `!important`, overriding the older 44×44 close target. The import modal also retained a centered desktop-dialog presentation with small supporting text rather than a phone-native viewport/safe-area treatment.

## Typography/readability assessment
The shared `agent-control-readability.css` already raises many Agent Control controls to a 13–14px baseline and 48px touch height on mobile, but it did not undo the hidden Add-your-sphere label or the 36px modal close target. The importer also retained 11px primary explanation text and 14px textarea content from the desktop layer. These are core workflow controls/content, so they cannot pass certification as microcopy.

Run 053 raises the audited mobile surface to the established SaaS baseline: workspace/import controls are 14–15px, importer primary explanatory copy is 15px, supporting/status text is 13px, the CSV editor is 16px, and critical touch controls are 44–48px minimum.

## Preserve vs. redesign decision
Preserve the horizontal Agent Control workspace navigation because four professional workspaces fit naturally as a swipeable command row and all destinations should remain directly reachable. Do not hide labels to force desktop density onto a phone.

Redesign the private-sphere importer on mobile as a bottom sheet rather than retaining the centered desktop modal. The importer is a high-intent task with potentially long saved-property/CSV content, so a `100dvh`-bounded sheet with contained scrolling, safe-area padding and finger-safe controls is more appropriate than shrinking its desktop dialog.
