**Timestamp:** 2026-08-21 20:33 ET

**Program:** Linear NJW-246

## Area audited

Marketing Studio admin analytics shell, typography/readability, period controls, KPI cards, funnel/segments, customer search/filter controls, customer ledger, production-order ledger, error/loading states, narrow-phone overflow, touch targets, and safe-area behavior.

## Finding

The route had a nominal `max-width:720px` breakpoint, but the mobile experience still preserved the desktop data-table model. Both the customer ledger and production-order ledger retained a `min-width:920px` nine-column table, with 9px headers/pills and 11px row text. On a phone this required prolonged horizontal panning and made member/order economics difficult to scan without zooming. The same route also retained 9px kickers/stat labels, 10px segment text, 12px navigation, and 38px search/filter fields.

This is a substantive mobile certification risk: the information technically existed, but the primary admin evidence surface was not comfortably readable or reviewable on a phone.

## Typography/readability assessment

Before this run, meaningful operational text frequently sat at 9–11px. Primary filtering controls were 38px high and inherited sub-16px input text. That is below the working Watchdog mobile standard for mature SaaS products.

Run 048 raises meaningful operational/supporting copy into the 12–15px range, keeps hero/body copy around 15px+, makes search/select controls 16px / 48px, and period/segment actions 44px+.

## Preserve-vs-redesign decision

**Redesign on mobile only.** The customer and order ledgers are decision-critical and cannot be omitted. However, preserving a 920px desktop table on a 320–430px device is not an acceptable mobile presentation.

Desktop keeps the existing nine-column tables unchanged. At `<=720px`, every ledger row is rendered visually as a stacked card while preserving all nine fields. Each field receives an explicit mobile label. At `<=440px`, each label/value pair stacks to one column for narrow-phone readability. No data, field, or workflow is removed.

## Change

Added `property/css/marketing-studio-admin-mobile-audit.css`, loaded only at `max-width:720px`.

Mobile changes include:

- Customer and production-order tables become full-information stacked cards instead of a 920px horizontal table.
- Every original table field remains visible with explicit mobile labels.
- Ledger row text is 14px; supporting email/status text 12–13px; long values wrap safely.
- Customer search and segment select are 16px with 48px heights.
- Period controls are 44px+ with 14px labels.
- Segment cards are 56px minimum and use 13–18px text.
- Hero, KPI, funnel, loading, and error-state typography was raised to the mobile SaaS baseline.
- Safe-area-aware side/bottom padding and `viewport-fit=cover` were added.
- Focus-visible treatment was added for major interactive controls.
