## Area audited

Mobile shell/navigation and exit reachability for the Marketing Studio Direct Mail Analytics admin route, with follow-up source review of the remaining async period/segment refresh and recovery boundary.

## Finding

The route's base `@media(max-width:720px)` rule explicitly set `.dmaa-top nav{display:none}`. That removed both explicit admin navigation destinations — **Campaigns** and **Dashboard** — on phones. The Marketing Studio brand link still returned to Marketing Studio, but a phone user lost the route choices that desktop users retained.

This is a substantive navigation/certification risk. Hiding primary admin navigation is not an acceptable mobile adaptation merely because it avoids header crowding.

## Typography/readability assessment

Run 048 had already raised primary mobile analytics copy, filters, ledger content, period controls, and segment controls to the Watchdog SaaS-mobile baseline. The hidden navigation itself was worse than an undersized-text problem because its labels were unavailable entirely.

The restored mobile navigation uses 14px bold interactive text on 44px minimum-height targets. The Marketing Studio brand remains 15–17px depending on narrow-phone width, and the Direct Mail context badge remains 11px rather than dropping back to the prior 9–10px operational sizing.

## Preserve-vs-redesign decision

**Redesign on mobile only.** The desktop header keeps its inline brand + right-aligned navigation. On phones, attempting to squeeze that same single-row composition would create crowding. Instead, the header becomes a compact two-level mobile command surface: the Marketing Studio identity stays on the first row and Campaigns/Dashboard become an equal-width two-button navigation row below it.

No navigation destination is removed or renamed.
