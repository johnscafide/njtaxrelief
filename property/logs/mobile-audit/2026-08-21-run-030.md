## Finding

The Customize route's remaining certification risk was the shared wizard footer/navigation on phones. In `property/css/marketing-studio-wizard.css`, `.mw-nav` becomes `position:sticky; bottom:0` at `<=620px`, but it did not account for `env(safe-area-inset-bottom)` and its navigation controls had no explicit 44px minimum touch size. The route viewport also lacked `viewport-fit=cover`, so safe-area CSS introduced in earlier mobile audit layers could not be relied upon on cutout/home-indicator iOS devices.

The route also exposes shared toast surfaces. Without mobile safe-area positioning, a bottom toast can compete with the iPhone home-indicator region or the sticky wizard navigation.

## Typography/readability assessment

The sticky wizard controls are primary navigation and now use 14px text at `<=700px` and 15px on phone-sized `<=620px` viewports, with 48px minimum height. Toast text is explicitly 14px with 1.4 line-height and unrestricted wrapping. This is consistent with the Watchdog mobile typography standard for interactive and transient operational UI.

## Preserve vs. redesign decision

**Preserve the sticky wizard navigation, harden it for mobile.** The Back/Next workflow is appropriate on phones and should remain persistent. Replacing it with another navigation model would add unnecessary interaction churn. The correct mobile treatment is safe-area-aware spacing, larger touch targets, visible keyboard focus, and viewport-aware toast positioning.

## Change

Added `property/css/marketing-studio-mobile-fixed-audit.css`, loaded only at `max-width:700px`, which:

- gives the mobile wizard header top/left/right safe-area awareness;
- gives the mobile stage left/right safe-area awareness;
- makes wizard navigation actions at least 44px wide by 48px high with 14–15px control text;
- adds explicit `:focus-visible` treatment to wizard navigation actions;
- gives the sticky `<=620px` wizard footer `safe-area-inset-bottom` clearance and a higher stacking context;
- repositions shared `.pl-toast` / `.ms-toast` surfaces above device safe areas, with 14px readable text and long-text wrapping.

Updated `property/marketing-studio/customize/index.html` to:

- add `viewport-fit=cover` to the viewport meta tag;
- load the fixed-surface audit stylesheet last, with `media="(max-width: 700px)"`.
