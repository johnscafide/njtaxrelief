## Finding

The Audience route already changed layout below 720px, but a large amount of operational text still inherited desktop-density sizing. Source review found 9–11.5px labels and supporting text across filters, panel kickers, property-result rows, Smart Audience cards/presets, source metadata, and credit context. Primary audience inputs were 14px, which also creates an iOS focus-zoom risk. Filter chips and town autocomplete suggestions did not have a deterministic 44px+ touch target. The page therefore technically fit on a phone while still failing the Watchdog mobile readability/touch standard.

## Typography/readability assessment

**Before:** operational labels/supporting text commonly 9–11.5px; form fields 14px; several interactive chips/suggestions relied on padding rather than a certified touch height. This is materially denser than mature SaaS mobile interfaces and would require excessive concentration on smaller phones.

**After:** primary fields are 16px/48px; operational labels are generally 12–14px; property/audience descriptions are 13px with increased line-height; decision/action labels are 14px; important action rows are 44–48px+; property-result rows are at least 56px. Leaflet legal attribution remains intentionally compact at 10px because it is non-operational legal map attribution rather than a product decision control.

## Preserve vs redesign decision

Audience-building functionality is core to Marketing Studio, so no targeting modes or data were removed. The existing mobile architecture was preserved where it was already appropriate (horizontal mode scroller, stacked map/list layout), but desktop-density pieces were deliberately re-presented for mobile:

- Smart Audience presets remain cards, but use larger readable/tappable cards and collapse to one column at `<=420px`.
- Town autocomplete remains an anchored suggestion surface, but now has a contained `dvh` scroll region and 48px suggestion rows.
- Property results remain selectable rows, but become 56px+ decision rows with larger checkbox controls and readable metadata.
- Filter chips remain compact controls, but are now 44px minimum targets with 13px labels.
- The map remains available because it is a primary audience-building tool; at `<=420px` its height is capped relative to `dvh` so it does not monopolize the phone viewport.

## Change

Created `property/css/marketing-studio-audience-mobile-audit.css` and loaded it only at `max-width:720px` from the Audience route. The mobile layer:

- raises operational typography into a 12–16px range;
- sets main audience inputs/selects to 16px and 48px high;
- standardizes core action targets to 44–48px+;
- enlarges audience mode icons/cards;
- makes filters, town suggestions, property rows, Smart Audience presets, source cards, checkboxes, and direct-mail credit context readable/tappable;
- restores readable mobile map-empty guidance;
- contains autocomplete scrolling using `dvh`, overscroll containment, and momentum scrolling;
- adds visible `:focus-visible` treatment;
- adds `viewport-fit=cover` to the Audience document;
- adds narrow-phone one-column Smart Audience/action layouts and viewport-aware map height.
