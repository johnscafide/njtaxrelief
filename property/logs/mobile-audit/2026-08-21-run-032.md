## Finding

The Audience route had already received a first mobile typography/form pass, but the saved-area workflow still inherited desktop micro-UI from `marketing-studio-audience-saved-areas.css`: state/category labels at 8px, supporting metadata at 10px, a 12px saved-area name field, 34px action/delete controls, and nowrap/ellipsis behavior that could hide meaningful saved-area names and criteria on phones. Leaflet's default zoom/popup-close controls also did not have an explicit mobile 44px target guarantee. The sticky wizard Back/Next bar used `bottom:0` without explicit `safe-area-inset-bottom` clearance.

## Typography/readability assessment

**Failed before fix.** The 8–10px operational labels and 12px form value were below the Watchdog mobile certification baseline for meaningful SaaS workflow UI. Saved-area names/criteria are decision-support content and must remain readable without pinch zoom or forced truncation.

## Preserve vs. redesign decision

**Preserve the Saved Areas capability and map. Redesign mobile density only.** Saved audiences and the map are core Marketing Studio functions, so neither should be hidden on phones. The mobile presentation now expands touch targets and typography, allows meaningful saved-area text to wrap, stacks save actions on narrow phones, and retains the full Leaflet map with larger mobile interaction controls.

## Change

Updated `property/css/marketing-studio-audience-mobile-audit.css`, which the Audience route loads only at `max-width:720px`:

- Saved-area title/state/supporting text raised into the 12–14px range.
- Saved-area name input raised to 16px and 48px height to avoid iOS focus zoom and improve readability.
- Saved-area bar icon increased to 44x44.
- Saved-area action and delete controls now have 44px minimum touch targets; save controls remain 44px+.
- Saved-area names and criteria now wrap with `overflow-wrap:anywhere` instead of being forced into single-line ellipses.
- Empty-state copy raised to 14px.
- Leaflet zoom buttons and popup close control now have explicit 44x44 mobile targets; popup content is 14px with readable line height.
- Sticky wizard navigation now clears `env(safe-area-inset-bottom)` and uses 48px / 15px primary action sizing.
- At <=420px, save-area form actions stack full-width and saved-area state/actions can wrap instead of compressing.
