## Area audited
Final narrow-phone dashboard readability pass before certification, with emphasis on property-card metadata, explanatory copy, figure labels, and action controls.

## Finding
The dashboard layout itself is now substantially mobile-safe, but several inherited desktop typography rules remain too small for narrow phones. Source review confirmed `.brief` at 12px, `.pr-sub` at 13px, figure labels around 11px, and secondary figure text at 11px. Property action controls also rely on small text/padding rather than a deterministic finger-safe minimum height. This creates a real readability and touch-target risk on 320–420px devices even though the cards fit the viewport.

## Change
Updated `property/css/dashboard/dashboard-mobile-audit.css` inside the existing `@media (max-width: 420px)` mobile-only block:
- Increased dashboard brief/explanatory copy to 14px.
- Increased property subtext to 14px with safe wrapping.
- Increased property summary copy to 15px.
- Increased figure labels and secondary metric text to 12px.
- Tightened action-row spacing for narrow screens.
- Standardized property action links/buttons to a 44px minimum height with 14px text and `touch-action: manipulation`.

## Desktop isolation
**PASS.** The changes live only inside the dashboard mobile certification stylesheet, which is itself loaded using `media="(max-width: 768px)"`, and the new typography/action rules are further restricted to `@media (max-width: 420px)`. No desktop stylesheet or desktop selector was changed.
