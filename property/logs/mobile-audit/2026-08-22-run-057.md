# Watchdog Mobile Audit — Run 057

**Timestamp:** 2026-08-22 04:33 ET  
**Page:** `/property/agent-desk/` — Agent Control  
**Area audited:** Dynamic list/territory forms, weekly digest preference, loading/gate/transient feedback, narrow-phone form density

## Finding
After the queue, territory/funnel and evidence-drawer passes, several remaining Agent Control phone workflows still inherited desktop-density styling. The dynamic list and territory forms did not have a guaranteed 16px mobile input baseline or 48px controls, quick-play/list controls remained compact, the weekly-digest preference was still presented as a small desktop switch/label, and loading/gate/toast surfaces did not have a route-specific readable/safe-area mobile treatment. These are operational controls and status surfaces, not decorative microcopy, so they remained a certification risk.

## Typography/readability assessment
Primary explanatory copy is now 14px, form labels 13px, operational/supporting state text 12–13px, form inputs/selects 16px, and primary action text 14–15px. This removes remaining desktop-style micro-control typography from these workflows and avoids iOS focus zoom on the audited form controls.

## Preserve vs. redesign decision
Preserve all list-building, territory, digest, gate and status functionality because each is part of the Agent Control workflow. Re-present only the phone/tablet layout: operational forms use a two-column mobile grid that becomes one column at <=420px; quick plays collapse from three compact desktop-style controls to full-width narrow-phone rows; the digest preference becomes a finger-safe preference row; toast/gate feedback becomes safe-area-aware rather than being hidden or removed.
