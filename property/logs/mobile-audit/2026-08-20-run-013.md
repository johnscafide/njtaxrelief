## Area audited
Mobile navigation typography/readability, property selector/action command row, narrow-phone information hierarchy, touch targets, text wrapping, and preserve-vs-redesign behavior for the desktop command strip.

## Finding
The Property Home drawer had already received safer mobile touch dimensions, but its live source still inherited desktop-compression typography from `property/css/home/home-shell-fixes.css`: navigation labels were 11px and the Sign out label was 10px. The drawer therefore remained readable only in the technical sense, not at the typography standard expected for a modern SaaS mobile interface.

The property selector/action row was also still fundamentally a desktop command strip: Dashboard back navigation, Viewing label, property selector, monitoring state, Add Property, Glossary, and Print were designed as one wide desktop grid. On phone widths that information density risks compressed controls, awkward wrapping, and a selector that is too small for comfortable native mobile interaction.

## Typography/readability assessment
**FAIL before fix / PASS for audited surfaces after fix.**
- 10–11px operational navigation/action text was below the new Watchdog mobile certification baseline.
- The property selector now uses 16px text to remain comfortably readable and avoid iOS input zoom behavior.
- Navigation labels are now 15px; Sign out and command actions are 14px; the small brand descriptor is 11px because it is nonessential supporting identity text.
- Monitoring status remains 13px supporting text with normal wrapping.

## Preserve-vs-redesign decision
**Redesign for mobile, preserve desktop.** The desktop selector/action row contains useful functionality, so nothing important was removed. Instead of shrinking the desktop grid, mobile now receives a dedicated command stack:
- Dashboard and monitoring state form the first row where space allows.
- The Viewing label and property selector receive their own full-width rows.
- Add Property, Glossary, and Print become a touch-friendly action grid.
- At <=480px, the entire command row becomes one column for hierarchy, with Add Property spanning the full width above Glossary and Print.

This keeps all desktop functionality available while presenting it in a phone-native order.

## Change
Updated `property/css/home/home-mobile-audit.css` only:
- Raised drawer navigation labels from inherited 11px to 15px with 48px minimum rows.
- Raised Sign out from inherited 10px to 14px with a 48px minimum target.
- Raised drawer icon sizing to 15px and brand descriptor to 11px.
- Replaced the compressed desktop property command grid at <=820px with named mobile grid areas.
- Set the property selector to full width, 48px high, and 16px text.
- Made Dashboard, Add Property, Glossary, and Print 44px+ touch targets with 14px action text.
- Allowed monitoring status and action labels to wrap rather than overflow.
- Added a <=480px layout that stacks status/selector content and makes Add Property the full-width primary action.
