# Mobile audit run 065 — Dashboard controls, weather, and Voice

Date: 2026-08-23
Route: `/dashboard`
Linear: NJW-246, NJW-265
Evidence source: authenticated iPhone screenshots supplied by product owner plus current `main`/production runtime inspection.

## Reported defects

1. The blue Add Property action rendered as an unlabeled blank square on mobile.
2. Dashboard header weather was intentionally hidden by the existing mobile override and therefore absent beside notifications.
3. The contextual Ask Watchdog sheet rendered typed Ask controls but no visible Voice control on mobile.

## Root cause evidence

- `dashboard-mobile-audit.css` explicitly hid `.wd4-weather-chip` at widths <= 768px.
- `dashboard-v2-actions.js` injects the Add Property action, but the compact mobile presentation did not retain a guaranteed visible plus affordance.
- `watchdog-intelligence-voice.js` installed its contextual-panel MutationObserver only after the signed-in runtime resolved. A mobile startup race could therefore return before observation was installed, leaving future `#dwa-panel` instances without `#dwa-voice`.
- Production Supabase remained healthy and already exposed the entitlement/Analyst tables and active `intelligence-analyst` function needed by the existing governed Intelligence path. No database or RLS change was required for this presentation/runtime repair.

## Changes shipped

- Added `property/css/dashboard/dashboard-mobile-polish-20260823.css`.
  - Forces a visible `+` inside the 44px blue Add Property action.
  - Restores a compact mobile weather chip beside notifications.
  - Gives contextual Voice and Ask controls explicit full-width, 44px+ mobile targets.
- Added `property/js/dashboard/dashboard-mobile-polish.js`.
  - Requests browser geolocation only on mobile.
  - Uses current device coordinates for header weather through NWS, with Open-Meteo fallback.
  - Does not persist precise device coordinates to Watchdog storage.
  - Falls back to the Dashboard's existing saved-property weather if geolocation is denied or unavailable.
  - Reapplies the compact weather presentation after Dashboard rerenders.
- Updated `property/js/watchdog-intelligence-voice.js`.
  - Starts contextual-panel observation before auth/runtime resolution completes.
  - Lazily resolves the Supabase/auth client with a bounded retry.
  - Preserves the existing entitlement status check, transcript-before-submit rule, no-raw-audio-retention boundary, and governed Analyst composer.
- Updated `property/dashboard/index.html` to load the new mobile polish assets after the premium layers.
- Added `property/tests/dashboard-mobile-polish-contract.mjs` covering the Add Property plus affordance, mobile weather visibility/current-location request, and Voice bootstrap ordering.
