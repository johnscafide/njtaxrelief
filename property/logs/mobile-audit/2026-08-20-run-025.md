# Watchdog Mobile Audit — Run 025

**Timestamp:** 2026-08-20 21:34 ET  
**Page:** `/property/marketing-studio/customize/`  
**Area audited:** Marketing Studio front/back review path, creative approval destination, Watchdog Designs handoff workflow, workflow typography, touch targets, focus visibility, and narrow-phone action layout.

## Finding

The approval path was functionally wired, but the decisive mobile controls still depended on desktop-density styling. `marketing-studio-wdd-handoff-ux.js` correctly converts the upper handoff action into a “Review & approve below” control and scrolls/focuses the real creative approval button (`#msc-approve` / `[data-pv-approve]`). However, the handoff stylesheet still used a 13px primary action with no deterministic 44px minimum target, workflow step copy remained 11–12px, and the actual approval destination did not have an explicit mobile size guarantee outside the generic inspector action rule.

That created a certification risk in one of the most consequential Studio interactions: users could reach approval, but the path still required desktop-like precision and the workflow explanation was denser than the mobile typography baseline.

## Typography/readability assessment

**Failed before change.** The handoff sequence is operational decision-support UI, not decorative microcopy. Step descriptions at 11px and a 13px decisive action were too small/dense for the strengthened Watchdog mobile standard. Primary handoff explanation now uses 14px body copy; step/status text uses 12–14px; decisive actions use 15px.

## Preserve vs. redesign decision

- **Preserve:** the existing approval state machine, server approval call, handoff sequencing, front/back creative artifact, and the existing “scroll to real approval control” behavior.
- **Redesign for mobile:** the handoff presentation and action sizing. The workflow remains a vertical mobile sequence, but its labels, explanatory copy, icons, and decisive controls are enlarged. On phones <=420px, handoff and approval actions become full-width rather than retaining compact desktop button proportions.

## Change

Updated the existing mobile-only `property/css/marketing-studio-mobile-audit.css` certification layer.

Mobile changes include:

- Watchdog Designs handoff container tightened to phone-appropriate padding/radius;
- handoff heading remains prominent at 19px;
- explanatory/contract/supporting workflow copy raised to 14px with 1.5 line-height;
- workflow step titles raised to 14px and descriptions to 13px;
- workflow icons raised to 18px;
- handoff state remains compact but readable at 12px;
- `.wd-handoff-primary`, `#msc-approve`, `[data-pv-approve]`, and `[data-wdd-review-approve="true"]` now have explicit 48px minimum height, 44px minimum width, 15px action text, and `touch-action: manipulation`;
- approval/handoff controls receive visible keyboard `:focus-visible` outlines;
- approval destinations receive `scroll-margin-block` so programmatic review scrolling does not leave the decisive action tight against browser/UI chrome;
- at <=420px, handoff/approval actions become full-width for easy one-handed tapping.
