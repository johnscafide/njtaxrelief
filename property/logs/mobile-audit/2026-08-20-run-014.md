## Area audited
Mobile Agent Intel sheet, compact intelligence typography, long drill-down/accordion readability, long-value wrapping, table overflow, touch sizing, and preserve-vs-redesign behavior for desktop-density intelligence modules.

## Finding
Property Home already converts Agent Intel into a mobile bottom sheet, but compact intelligence styles still expose desktop-density type scales in the underlying component system: persona labels as small as 8px, compact kickers around 9px, trust copy around 9.5–10px, compact action controls around 10.5px, and expanded card/report copy around 11.5px. The Property Home report layer also retained 10px scorecard labels, 10.5px professional-note labels, and dense accordion bodies that had no explicit long-value/table overflow protection.

This is a mobile certification risk even when the layout technically fits: important evidence and action context can be difficult to scan, and long URLs/identifiers/table rows can force awkward overflow.

## Typography/readability assessment
**FAIL before fix / PASS for audited surfaces after fix.**
- Agent Intel primary title is now 20px and supporting mobile copy is 14px with 1.5 line-height.
- Intelligence kickers are now 12px; persona/supporting trust text is 11–12px; reason chips are 13px.
- Agent Intel buttons are 14px with 44px minimum targets; selects use 16px text.
- Property Home scorecard and professional-note labels are now 12px; explanatory values are 14px.
- Accordion titles remain 16px with 56px minimum header targets.

## Preserve-vs-redesign decision
**Preserve content, redesign density for mobile.** Agent Intel and deep Property Home drill-downs contain useful decision evidence and should not be removed from phones. The desktop information model is retained, but the mobile sheet now promotes typography, removes compact line clamping for important copy, stacks narrow Agent Intel header content at <=480px, and forces safe wrapping/scroll behavior for long values and tables.

## Change
Updated `property/css/home/home-mobile-audit.css` only:
- Made the Agent Intel sheet dynamic-viewport aware and explicitly prevented horizontal sheet overflow.
- Preserved the existing 44px close target and enforced 44px+ controls throughout the mobile Intelligence sheet.
- Raised compact intelligence kickers, persona labels, trust copy, reasoning text, body copy, and action typography to mobile-readable values.
- Removed mobile line clamping from important Agent Intel explanatory text.
- Set Intelligence select controls to 16px to remain readable and avoid iOS focus zoom behavior.
- At <=480px, stack the Intelligence header/persona presentation rather than squeezing the desktop composition.
- Raised Property Home scorecard/professional-note labels from inherited ~10–10.5px to 12px and supporting values to 14px.
- Enforced 16px accordion titles and 56px minimum accordion header targets.
- Added `overflow-wrap:anywhere` protection for long drill-down values/links and contained wide tables in horizontal momentum scrolling rather than allowing page-level overflow.
