# Watchdog Mobile Responsiveness Audit — Run 046

- **Timestamp:** 2026-08-21 18:37 ET
- **Page:** `/property/marketing-studio/design/`
- **Area audited:** Design/template selection library, filter/search controls, template cards, proof/selection actions, inspector fields, sticky wizard navigation, mobile typography, safe areas.

## Finding
The Design route already collapsed its template gallery to one column below 900px/760px, but the actual operational UI remained desktop-dense on phones. Current shared/template CSS exposed 9–10px kickers/tags, 11–12px supporting text, 12px template actions with only 8px vertical padding, a 32×32 inspector close action, and form fields without an explicit 16px mobile input baseline. The sticky wizard navigation also lacked route-specific home-indicator clearance.

This was a certification risk because template choice, proof review, provider approval/rejection, and variable editing are primary Design workflow actions, not decorative microcopy.

## Typography/readability assessment
**Failed before change.** Several meaningful labels were below the Watchdog mobile standard and core template/proof actions were visually and physically undersized. Long supporting copy could become dense even though the gallery technically fit.

**After change:** primary explanations are 14–15px, template titles 17px, supporting template copy 14px, operational labels 12–13px, controls/actions 14–16px, and primary inputs/selects use a 16px mobile font with 48px minimum height.

## Preserve vs. redesign decision
**Preserve the template-card model, redesign its mobile density.** A one-column card gallery is already an appropriate mobile information architecture, so replacing it with a different component would add unnecessary interaction cost. Instead, the mobile presentation now makes tabs horizontally scrollable/snap-friendly, enlarges the template/proof actions, increases card text readability, and keeps proof/inspector controls finger-safe.

The creative/proof artwork itself is preserved as artwork rather than reflowed, because changing its geometry would alter the artifact being reviewed.

## Change
Added `property/css/marketing-studio-design-mobile-audit.css`, loaded only at `max-width:720px` from the Design route. The layer:

- raises meaningful Design/template typography into the 12–17px mobile range;
- makes template/proof/provider actions 48px minimum with 14px labels;
- makes inspector close 44×44px;
- makes library search/select and variable inputs 16px / 48px;
- turns template tabs into a contained horizontal snap scroller with 44px targets;

- adds visible `:focus-visible` treatment;
- hardens sticky Back/Next controls to 48px / 15px;
- adds safe-area clearance for the sticky wizard navigation and Design stage;
- enables `viewport-fit=cover` on the route.
