# Mobile audit run 066 — Roomier Dashboard and Property Portfolio

Date: 2026-08-24
Route: `/dashboard`
Linear: NJW-246
Evidence source: authenticated iPhone screenshots supplied by product owner, current GitHub `main`, production Supabase project state, and Vercel deployment state.

## Reported mobile issues

1. Current-location weather in the top bar was too small relative to the other header controls.
2. Dashboard KPI and analytics cards felt compressed and visually crowded on a phone.
3. Several analytical and connected-data cards were being presented with desktop-like density instead of using the available vertical scroll space.
4. Property Portfolio was difficult to scan because table columns were compressed and values truncated. The preferred interaction is the larger Property Lookup table pattern: readable columns with intentional horizontal scrolling for additional data.

## Changes shipped

- Added `property/css/dashboard/dashboard-mobile-roomy-20260824.css`, scoped to `max-width: 768px` and loaded through a matching media attribute.
- Increased the mobile weather surface, icon, and temperature typography while preserving the existing current-location weather runtime.
- Changed dashboard bands to explicit full-width mobile rows so cards can use one line each rather than competing for narrow columns.
- Increased mobile spacing, card padding, radii, KPI values, labels, and vertical room for the map, Recent Activity, analysis surfaces, municipality intelligence, connected/premium cards, and secondary cards.
- Reworked Property Portfolio as a full-width, auto-height mobile card whose data table has readable column widths and intentional horizontal scrolling. The page retains vertical scrolling rather than trapping the user inside a short internal table viewport.
- Updated the mobile loading skeleton to match the one-column presentation.
- Added `property/tests/dashboard-mobile-roomy-contract.mjs` with source-contract checks for the mobile-only boundary, one-card-per-row KPI layout, larger weather surface, and Property Portfolio horizontal table behavior.
