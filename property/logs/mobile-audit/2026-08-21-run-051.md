# Watchdog Mobile Audit — Run 051

**Timestamp:** 2026-08-21 23:33 ET  
**Page:** `/property/marketing-studio/admin/`  
**Area audited:** Direct Mail Analytics mobile ledgers, narrow-phone overflow, typography/readability, transient/recovery integration

## Finding
The authoritative `main` source no longer contained the previously audited mobile card treatment for the two Direct Mail Analytics ledgers. Both customer activity and production orders had reverted on phones to the base `min-width:920px` desktop tables, forcing horizontal panning across nine columns and exposing 9–11px operational text. This was a substantive mobile usability and certification regression risk because customer spend/credit and order economics are decision-critical admin data.

## Typography/readability assessment
The base ledger headers and pills were 9px and table rows 11px. Mobile now presents ledger labels at 12px, row values at 14px, supporting email/metadata at 13px, and pills at 12px. Adjacent hero, stat, funnel, segment, and card-supporting text were also raised into the current Watchdog mobile baseline (generally 12–15px) while search/select fields remain 16px.

## Preserve vs. redesign decision
Preserve every ledger field and the existing desktop table presentation. Redesign only the mobile/tablet presentation: hide table headers visually within the mobile breakpoint and render each row as a labeled stacked card. Customer cards retain Member, Plan, Segment, Campaigns, Orders, Pieces, Spend, Credit, and Last order. Production cards retain Campaign, Status, Format, Size, Pieces, Retail, PCM cost, Gross margin, and Submitted. At <=440px each label/value pair becomes a single-column stack. No decision-critical data is omitted.

## Change
- Restored a mobile-native card presentation for both 9-column ledgers inside `property/css/marketing-studio-admin-mobile-audit.css`.
- Removed page-level/table horizontal scrolling on mobile by overriding the 920px table minimum width only inside `max-width:720px`.
- Added explicit mobile labels for every customer and production-order field using route-specific table selectors.
- Added safe wrapping for emails, long values, pills, and empty states.
- Raised operational typography across the mobile analytics surface to the current Watchdog SaaS-mobile baseline.
- Added `overflow-x:hidden` to the mobile admin root and full-width stacked search/filter controls at <=440px.
