# Watchdog Mobile Audit — Run 022

**Timestamp:** 2026-08-20 18:34 ET  
**Page:** `/property/pro`  
**Area audited:** Data Center preview, evidence cards, platform comparison, capability wall, FAQ typography/readability

## Finding
The Pro page still contained a material mobile certification risk in the Data Center preview. The desktop grid uses eight columns with a minimum width of 1050px, but `.pro-data-grid` inherited `overflow:hidden`. On narrow phones, columns beyond the visible viewport were clipped rather than reachable. Several adjacent evidence/platform/capability surfaces also retained desktop microcopy in the 7–11px range, including data-table headers/cells, platform kickers/badges, evidence labels, gauge/supporting labels, capability items, and feature-river labels.

## Typography/readability assessment
The layout technically fit the page because the wide Data Center content was being clipped, not because it was truly responsive. That fails the Watchdog mobile standard: important information must be readable and reachable without pinch-zoom. Operational text under roughly 11–12px also remained below the target baseline for a mature SaaS mobile experience.

## Preserve vs. redesign decision
The Data Center preview is strategically useful because it communicates the depth of Pro+ and the shape of high-volume data work. It should not be removed on mobile. The correct mobile treatment is a contained horizontal data scroller rather than shrinking eight columns into an unreadable phone-width table or hiding columns. Evidence, platform comparison, capability, and FAQ content remain appropriate as stacked mobile cards, so those sections were preserved and their typography/density was corrected rather than replaced.

## Change
Mobile-only rules at `max-width:720px` were added to `property/css/pro-conversion.css`:

- Data Center grid now scrolls horizontally inside its own component with momentum scrolling, contained overscroll, and touch pan behavior.
- Data rows use a deliberate 760px working width on mobile instead of the inherited 1050px desktop grid; narrow phones use 720px.
- Data table cells are raised to 12px, headers to 11px, and toolbar/chip controls to 12–14px.
- Data Center toolbar wraps cleanly and preserves Property/Town/County/Columns-live context instead of hiding all toolbar context at the older phone breakpoint.
- Data chips become an intentional horizontal scroller instead of wrapping into a dense micro-label block.
- Platform comparison kickers/badges/notes are raised to 12–15px, with larger visual indicators.
- Evidence card labels/supporting values are raised to 12–15px.
- Capability wall items are raised to 14px and headings to 18px; explanatory copy is 14px.
- FAQ body copy is raised to 15px with 1.6 line-height and 48px visual icons.
- Workflow supporting notes are raised to 13px.
