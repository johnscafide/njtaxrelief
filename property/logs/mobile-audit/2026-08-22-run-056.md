# Watchdog Mobile Audit — Run 056

**Timestamp:** 2026-08-22 03:38 ET  
**Page:** `/property/agent-desk/` — Agent Control  
**Area audited:** Evidence drawer / sourced-touch-reason detail surface

## Finding
The Agent Control evidence drawer remained a desktop side drawer on phones. Its base implementation used a full-height right-side panel with compact evidence-score labels, while the runtime only toggled `hidden`, blocked body scroll, and restored body overflow. The drawer had no mobile-specific focus lifecycle, Escape-to-close behavior, Tab containment, or return-focus behavior. Although the close control was already 44px in the base CSS, the overall interaction still failed the stronger mobile modal/drawer certification standard.

## Typography/readability assessment
The evidence drawer contains decision-critical explanation, source, limitations and conversation guidance. It cannot be treated as secondary microcopy. On mobile, Run 056 uses 23px drawer title text, 18px section headings, 15px explanatory/body copy, 14px limitation/action text, and 12px score labels/eyebrow text with normal line-height and safe wrapping.

## Preserve vs. redesign decision
Preserve all evidence and source information because it is core to Watchdog's explainability and professional workflow. Replace only the phone/tablet presentation: instead of a narrow full-height desktop side rail, present the same content as a safe-area-aware mobile bottom sheet with contained scrolling and explicit focus/keyboard behavior.
