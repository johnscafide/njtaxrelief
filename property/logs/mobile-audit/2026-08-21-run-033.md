# Watchdog Mobile Audit — Run 033

- **Timestamp:** 2026-08-21 05:34 ET

- **Program:** Linear NJW-246
- **Area audited:** Municipality autocomplete keyboard/focus behavior, assistive-technology semantics, loading/result announcements, mobile-only interaction isolation

## Finding

The Audience route's municipality autocomplete surfaces were visually usable on phones but functionally mouse/touch-first. Both `#msa-town` and `#msa-smart-town` rendered clickable suggestion buttons, but the inputs did not expose combobox/listbox semantics and had no Arrow Up/Down, Enter-to-select, or Escape-to-dismiss interaction. Dynamic search/results also had no mobile-specific live announcement. This creates a substantive certification risk for keyboard and assistive-technology users even though the suggestion list technically fits the viewport.

## Typography/readability assessment

**PASS from Runs 031–032; interaction accessibility failed before this run.** Suggestion rows are already 14px with 48px minimum touch height under the Audience mobile audit stylesheet. The problem was not text size in this pass; it was that readable suggestions were not equivalently operable from the keyboard or clearly exposed to assistive technology.

## Preserve vs. redesign decision

**Preserve the autocomplete presentation and enhance its mobile interaction model.** The existing stacked input + contained suggestion list is appropriate for phones and does not need a visual rebuild. The mobile presentation now behaves like an accessible combobox/listbox without changing the desktop autocomplete implementation.

## Change

Added `property/js/marketing-studio-audience-mobile-a11y.js`, which exits immediately above 720px and enhances dynamically rendered Audience municipality inputs on mobile/tablet only:

- Adds `role="combobox"`, `aria-autocomplete="list"`, `aria-controls`, `aria-expanded`, `aria-haspopup`, listbox/option semantics, and `aria-activedescendant`.
- Adds Arrow Down/Up navigation through visible suggestions.
- Adds Enter selection for the active suggestion and Escape dismissal.
- Keeps active options scrolled into the contained suggestion viewport.
- Adds polite live-region announcements for search start, result count/no-match state, dismissal, and selection.
- Uses `aria-busy` while a mobile municipality search is awaiting dynamic results.
- Uses a MutationObserver so the enhancement survives the Audience route's dynamic mode re-rendering.

Added `property/css/marketing-studio-audience-mobile-a11y.css`, loaded only at `max-width:720px`, to provide a clear active-option state and expanded-input state while keeping the live status visually hidden.

Updated `/property/marketing-studio/audience/index.html` to load the new CSS only at the mobile breakpoint and wire the mobile behavior shim after the existing Audience runtime scripts.
