## Run 001 — 21:21 ET

### Page
`/property/` — `property/index.html`

### Area audited
Scrolled mobile navigation and sticky address-search behavior.

### Finding
**Major usability defect.** The solid Watchdog navigation (`.wd-nav.solid`) becomes fixed at `top: 0`, while the sticky search (`.ssearch`) was also fixed at `top: 0`. The sticky search uses the higher base z-index, which could cover the mobile navigation after the hero is passed.

### Change
Updated `property/css/public-mobile-nav.css` with mobile-only offsets:
- `<= 940px`: sticky search starts at `top: 72px`.
- `<= 560px`: sticky search starts at `top: 78px` to account for the larger 48px mobile header controls and 15px vertical padding.

### Desktop isolation
**PASS.** New behavior is entirely inside `@media(max-width:940px)` and `@media(max-width:560px)`. Desktop `>= 941px` behavior is unchanged.

## Run 002 — 22:22 ET

### Page
`/property/` — property details modal opened from `property/index.html`

### Area audited
Narrow-phone modal toolbar, horizontal fit, and touch-target sizing.

### Finding
**Major usability / overflow risk.** The mobile modal hides labels on `.plm-barbtn`, but the left-side `.plm-back` retained the full “Back to search” text. Combined with four action controls (Save, Share, Sign in, More), the toolbar could exceed a 320px viewport once base padding and gaps were included. This risked clipping or compressing critical modal navigation/actions on narrow phones.

### Change
Updated `property/css/public-mobile-nav.css` with a `@media(max-width:700px)` modal-toolbar override scoped to `body.wd-consumer-mode`:
- Converted the Back control to an icon-only 44x44 touch target on mobile.
- Standardized Save, Share, Sign in, and More to 44x44 touch targets.
- Reduced mobile-only toolbar padding/gaps.
- Allowed the action group to shrink correctly with `min-width:0` while keeping actions right-aligned.

### Desktop isolation
**PASS.** Every new toolbar rule is inside `@media(max-width:700px)` and scoped to `body.wd-consumer-mode`. Desktop behavior remains unchanged.

### Verification evidence
- Existing source inspection confirmed `.plm` becomes full-screen at `<=700px` and action-label spans are already hidden there, but `.plm-back` text was not compacted.
- Post-write GitHub verification confirmed the new mobile-only toolbar rules are present on `main`.
- Mobile control budget is now deterministic: five 44px controls = 220px, plus 16px toolbar horizontal padding and minimal gaps, safely inside a 320px viewport.
- Commit: `4a8d11bbdf8932108cbf7b13c5c94f4359730a80`.

### Certification
- Major item reviewed: **PASS**
- Major item fixed: **PASS**
- Touch targets: **PASS for modal toolbar**
- Horizontal fit risk: **CLEARED for modal toolbar**
- Desktop untouched: **PASS**
- Entire page Mobile Certified: **NOT YET**

The landing page still needs search/autocomplete interaction review, lower-page overflow/typography/image checks, and remaining modal body interactions before full certification.
