## Finding
The authoritative `main` branch still inherited the shared wizard rule that makes `.mw-nav` sticky at `bottom:0` below 620px. The Review-specific mobile audit layer did not override that behavior. On iPhones and other gesture-navigation devices, the final Back/Next controls therefore had no explicit home-indicator clearance and could sit too close to the system gesture region. The shared wizard controls also relied on desktop padding rather than a deterministic mobile target size.

## Typography / readability assessment
Review's substantive evidence/pricing typography remains within the strengthened mobile baseline from Run 043. The uncovered issue was the fixed navigation surface itself: final actions need normal SaaS-mobile control text and reliable finger targets. Run 044 standardizes the wizard actions at 15px text on 48px minimum targets and keeps transient toast text at 14px with safe wrapping.

## Preserve vs redesign decision
Preserve sticky Back/Next navigation because it is useful on a long final-review page and keeps the primary workflow actions reachable. Do not remove it or convert it to a floating overlay. Instead, harden the existing mobile presentation with safe-area-aware spacing, extra stage clearance, route-scoped focus treatment, and viewport-safe transient messaging. Desktop remains unchanged.
