# Watchdog Mobile Audit — Run 037

- **Timestamp:** 2026-08-21 09:38 ET
- **Page:** `/property/marketing-studio/recipients/`
- **Area audited:** recipient-source selection, mailing preflight/readiness evidence, sample label, sticky wizard navigation, typography/readability, touch sizing, safe-area behavior

## Finding

The Recipients route inherited a responsive layout, but important decision-support UI was still desktop-density on phones. The mailing preflight surface used 9px section/metric labels, 9–10px supporting rule copy, 10–11px sample-label text, and 38px preflight actions. Recipient-source metadata also included 10px badges/metadata and a desktop-oriented source selector. The route did not declare `viewport-fit=cover`, weakening safe-area handling for its sticky wizard navigation and transient source toast.

This is a certification risk because users must be able to verify recipient source, mailing readiness, address hygiene, and label evidence without pinch-zoom or precision tapping.

## Typography/readability assessment

**Before:** operational preflight text commonly 9–10px; sample-label text 10–11px; recipient-source metadata/badges 10–12px; actions as small as 38px high.

**After:** primary explanation copy is 15px; source names 15px; source detail text 13px; preflight labels/rules/supporting text 12–13px; sample-label content 13–14px; preflight actions and wizard navigation use 15px text on 48px minimum targets. Narrow-phone preflight metrics/rules collapse to one column at `<=420px` rather than compressing text.

## Preserve vs. redesign decision

The recipient-source and mailing-preflight information is decision-critical and remains available on mobile. It was **preserved but re-presented**: source selection becomes a full-width finger-safe workflow; metadata can wrap; preflight evidence keeps all metrics/rules but uses a two-column mobile grid that becomes one column on narrow phones; primary verification actions become full-width controls. No evidence was hidden or removed for mobile.

## Change

Created `property/css/marketing-studio-recipients-mobile-audit.css` and loaded it only at `max-width:720px` from the Recipients route. The new layer:

- raises mobile operational typography into the 12–15px range;
- gives the source toggle a 48px target and source rows a 64px minimum height;
- removes single-line truncation from meaningful source names/details;
- converts preflight microtype to readable 12–14px evidence text;
- gives preflight actions and Back/Next controls 48px minimum touch heights;
- adds focus-visible treatment to critical controls;
- adds safe-area-aware stage, toast, and sticky wizard-nav spacing;
- adds `viewport-fit=cover` to the Recipients route;
- collapses preflight grids to one column below 420px.
