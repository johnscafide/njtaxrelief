# Watchdog Mobile Audit — Run 055

**Timestamp:** 2026-08-22 02:33 ET  
**Page:** `/property/agent-desk/` — Agent Control  
**Area audited:** Territory Intelligence + Value Created/funnel modules

## Finding
Agent Control still had a substantive mobile usability and certification risk in the Territory Intelligence surface. The current desktop-oriented territory row used a four-column grid (`34px / content / auto / 30px`) and the trailing territory action was explicitly only 30px wide. Even with the prior global readability layer increasing many control heights, the phone presentation still compressed decision-critical territory information and retained a too-narrow action target. The adjacent funnel also inherited desktop-density labels and an information layout designed for wider screens.

## Typography/readability assessment
Territory names, territory context, funnel stages and conversion notes are operational intelligence, not decorative captions. On mobile they need normal SaaS scanning density. Run 055 uses 15px territory names, 13px supporting territory text, 12px secondary metadata, 14px funnel stage text, 12px funnel supporting notes, 19px section headings, 14px button labels and 16px select text.

## Preserve vs. redesign decision
Preserve both Territory Intelligence and Value Created because each is decision-critical to Agent Control. Do not hide or reduce the data. Re-present each territory row as a two-column mobile card row: a 44px icon plus readable content on the first row, with the two territory actions occupying a dedicated second row as full-width finger-safe controls. Preserve the funnel as a vertical progression, but increase text/progress-bar density and stack header controls on very narrow phones.
