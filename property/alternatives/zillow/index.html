The misunderstanding to avoid

Zestimate versus assessed value

Zillow says its Zestimate is a model-based estimate of a home's market value using public records, MLS data and user-submitted details. Zillow also says it is not an appraisal. In New Jersey, an assessed value is part of the local tax system. Comparing the two numbers directly without the municipality's common level ratio can create a false impression that a property is over- or under-assessed.
