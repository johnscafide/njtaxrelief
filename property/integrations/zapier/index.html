Connect your Watchdog account

The connector uses a dedicated Watchdog API key that you create and control. Each key can be revoked independently.

STEP 1Open Integration CenterSign in to Watchdog and open the Integration Center.
STEP 2Create a Zapier keyName the key and select only the capabilities your workflows need.
STEP 3Copy it onceCopy the key when Watchdog displays it. Treat it like a password.
STEP 4Connect in ZapierAdd a Watchdog account in Zapier and paste the key when prompted.

What you can automate

The connector is intentionally split into instant triggers, property searches and governed actions.

TRIGGERS

React to Watchdog events

Property Signal Changed
Start a workflow when a governed property signal materially changes.

Watchlist Alert
Route Watchlist alerts into communication or task systems.

Report Ready
Continue a workflow when a requested Watchdog report is ready.

Intelligence Finding Created
Use approved Intelligence findings as a workflow trigger when the connection has Intelligence read permission.

SEARCHES

Find governed property context

Find Property
Resolve a property through Watchdog's public property contract.

Find Governed Property Snapshot
Retrieve an approved property snapshot for downstream workflow logic.

Owner/person fields are not part of the public Zapier property contract, and missing values remain missing rather than being invented.

ACTIONS

Send work back to Watchdog

Add / Remove Property from Watchlist
Keep a user's monitored set synchronized with workflow decisions.

Send CRM Context to Watchdog
Attach normalized workflow context without turning CRM data into property truth.

Run Watchdog Intelligence for Property
Queue an approved Intelligence model using the user's normal plan, quota and idempotency rules.

Permissions and data boundaries

A connection should receive only the capabilities it needs.

TRIGGER ACCESSReceive Watchdog eventsRequired for REST Hook subscriptions and event delivery.
PROPERTY ACCESSRead governed snapshotsAllows property search and snapshot retrieval.
CRM CONTEXTWrite normalized contextExternal relationship/workflow context remains separate from governed property facts.
INTELLIGENCERead and run separatelyReceiving findings and launching analyses are separate explicit permissions.

Troubleshooting

Most connection issues fall into a small number of categories.

Authentication fails

Create a new key from Integration Center and reconnect the Watchdog account. Do not email or paste a reusable key into support messages.

A trigger never fires

Confirm the Zap is enabled, the Watchdog key still has trigger permission, and the event is actually enabled for that connection. Intelligence findings also require explicit Intelligence read access.

An Intelligence action is rejected

Confirm Intelligence run permission, a supported model, a valid governed property identifier, and available plan quota. Retrying the same external event should use a stable source event or idempotency identifier.
