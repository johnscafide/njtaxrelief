ROBUST methodology

What is Coefficient of Deviation?

COD measures how closely individual assessment ratios cluster around the municipality's median ratio. A lower COD usually indicates more uniform assessments; a higher COD indicates greater variation. This tool converts that statistical measure into a relative consistency score and plain-language comparison.

How this tool score is calculated

The Uniformity tool score is a transparent consumer-facing index derived from the municipality's latest COD relative to the range in the loaded dataset. It is not an official state score. It also is not necessarily identical to the U component inside every version of the Watchdog Score, which remains governed and versioned separately.
