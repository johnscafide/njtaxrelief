About the measure

What is coefficient of deviation?

COD measures how closely individual assessment ratios cluster around the municipality's median ratio. A lower COD usually indicates more uniform assessments; a higher COD indicates greater variation. This tool converts that statistical measure into a relative score and plain-language comparison.

How the score is calculated

The fairness score is a transparent consumer-facing index derived from the municipality's latest COD relative to the range in the loaded dataset. It is not an official state score and should not be presented as one.
