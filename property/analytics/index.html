Privacy boundary: Watchdog Analytics is developer-only and aggregate-first. Event rows use audience classes rather than identities. It does not expose names, emails, addresses, PAMS PINs, search text, prompts, phone numbers or IP addresses. Signup acquisition links a newly created account to a consented anonymous Watchdog visitor/session, provider and sanitized first-touch metadata. It does not store auth error text, OTP codes, tokens, raw third-party query strings or ANCHOR form answers. Global Privacy Control and Do Not Track continue to disable the browser collector.
