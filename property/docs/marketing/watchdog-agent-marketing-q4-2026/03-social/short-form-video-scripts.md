## How to read this file

- Each script is meant to be filmed on a phone in one take. Talking head unless the b-roll note says screen recording.
- Target lengths are 20 to 60 seconds. Read the body out loud once with a timer before filming; cut sentences, never speed up.
- Sample addresses (123 Example Street, 456 Example Avenue, Example Township) are fictional. Every Watchdog screen shown must carry a "sample" or "representative" label and must never show a real customer's data.
- Property data is not seller intent. No script says or implies who is going to sell. If an ad-lib drifts there, reshoot.
- Phase 0 scripts (SV-001 to SV-010, before Oct 12) never mention the trial. They build the free lookup habit and the Founding Agent list.
- The only two offer phrases allowed on camera are "Start your 14-day Agent trial" and "Request a Founding Agent invite." The only prices allowed are $59 per month, $590 per year, $1,499 lifetime, $1.79 per card, and $29 for Watchdog Move.
