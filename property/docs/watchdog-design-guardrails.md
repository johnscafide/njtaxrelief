# Watchdog Design Guardrails

These rules apply to new Watchdog UI, marketing surfaces, product pages, graphics, cards, menus, dashboards, and future visual revisions.

## Decorative shape rule

Do not use decorative circles, corner orbs, bubble blobs, concentric circular overlays, or radial circle accents as background decoration.

This rule is about decorative motifs. It does not prohibit functional circular UI where the shape communicates a control or identity, such as avatars, close buttons, status indicators, map markers, or other conventional controls.

Prefer clean composition, typography, restrained linear gradients, spacing, photography, data visualization, and purposeful rectangular or softly rounded geometry instead.
