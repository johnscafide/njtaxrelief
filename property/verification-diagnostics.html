This checks each stage without exposing a verification code or owner information.

Deployment order

  1. Run the included Supabase migration.
  2. Set the Resend administrator-email secrets.
  3. Deploy the request-verify-code Edge Function with JWT verification.
  4. Submit one test request and confirm that the code and mailing address arrive in the administrator inbox.

The code is emailed only to the administrator, who mails it to the property on a postcard. It is never emailed to the requester, and no public owner name is used.
