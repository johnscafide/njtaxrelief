NJPTR WATCHDOG RELEASE 0.16.0
=============================

This package integrates Tax Rate Trajectory and the Statewide Fairness Index
throughout the existing /property experience.

------

3. Replace matching files when prompted.
4. Upload new folders and files as well as replacements.
5. Upload the root `sitemap.xml` to the website root.

SUPABASE AND POSTAL VERIFICATION
--------------------------------
These steps are required before Mail me a code can work:
1. Run both included Supabase migration files in timestamp order. The second
   safely converts an earlier PostGrid setup to administrator-email delivery.
2. Create the EmailJS template `template_verifymail` using the variables in
   supabase/functions/request-verify-code/EMAILJS-TEMPLATE-SETUP.md.
3. Add these Supabase Edge Function secrets:
   EMAILJS_PRIVATE_KEY, EMAILJS_PUBLIC_KEY, EMAILJS_SERVICE_ID,
   EMAILJS_TEMPLATE_ID, VERIFY_ADMIN_EMAIL, and VERIFY_FROM_EMAIL.
   Never place EMAILJS_PRIVATE_KEY in a website JavaScript file.
4. Review the complete secret list in
   supabase/functions/request-verify-code/README.md.
5. Deploy the request-verify-code Edge Function with JWT verification enabled.
6. Open /property/verification-diagnostics.html and run the checks.
7. Submit one test request. Confirm that the code and property mailing address
   arrive in your administrator inbox, then mail the postcard yourself.

STATE DATA AUTOMATION
---------------------
Commit the included .github/workflows/state-data-refresh.yml file to GitHub.
It validates data monthly and opens a review pull request when files change.
It never merges state data automatically.
