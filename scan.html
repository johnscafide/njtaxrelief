Every property in a town with a provable appeal case

This does not estimate what homes are worth. It reads the price each one actually sold for, verified by the State of New Jersey as a genuine arm's length transaction, and tests the current assessment against it using the Chapter 123 formula a county board applies. A property's own recent sale is the strongest evidence there is, and it needs no appraisal to stand up.

Verified sales currently on file cover 2024 to 2026. New Jersey publishes one sales file per year, so earlier years can be added as they are loaded.
