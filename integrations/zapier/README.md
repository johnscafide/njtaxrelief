# Watchdog for Zapier

Phase 2 of the Watchdog Integration Platform. This package is intended for Zapier Platform CLI and talks only to the dedicated `zapier-api` Edge Function.

## Authentication

Custom API-key authentication using `X-Watchdog-Key`. Keys are generated by the authenticated Watchdog `integration-key-manager` function, are displayed once, stored only as SHA-256 hashes, and may be revoked independently.

## Triggers

- Property Signal Changed (`property.signal.changed`)
- Watchlist Alert (`watchlist.alert`)
- Report Ready (`report.ready`)
- Intelligence Finding Created (`intelligence.finding.created`)

All four are REST Hook triggers. Zapier supplies a unique target URL when a Zap is enabled. Watchdog stores it as a Phase 1 outbound connection and removes/revokes it when the Zap is disabled.

## Searches

- Find Property
- Get Governed Property Snapshot

The public property contract intentionally excludes owner/person fields. Missing property values remain null rather than being inferred.

## Creates

- Add Property to Watchlist
- Send CRM Context to Watchdog

CRM context is stored separately from governed Watchdog property truth. This action does not enable Watchdog Intelligence access to CRM context by itself.

## Local developer flow

1. Use Node 22.
2. Install dependencies with `npm install`.
3. Run `zapier-platform test` and `zapier-platform validate`.
4. Authenticate the CLI with `zapier-platform login`.
5. Register the integration in the Zapier developer platform and push with `zapier-platform push`.

The Zapier developer deploy key belongs only in the developer environment (`~/.zapierrc`), never in this repository.
