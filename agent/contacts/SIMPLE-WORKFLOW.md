# Simplified Agent Contacts workflow

This small UI layer keeps the existing CRM Contact Cleanup and Watchdog Contact Intelligence logic intact while presenting a simpler first-run path:

**Upload → Analyze → Review**

When a contact file is open, the landing hero, stats, and CRM Companion promo are temporarily hidden so the working file and Analyze action stay in focus. Existing property-match, segmentation, opportunity, export, privacy, and compliance logic remains unchanged.
